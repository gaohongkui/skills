Public agent skills, written to the [Agent Skills](https://agentskills.io/specification)
open standard. One canonical source per skill; every catalog, index, and marketplace
manifest is generated, so nothing can drift.

Skill content is written in **Chinese**; every `description` ends with one English
trigger sentence, so English-speaking agents and the skills.sh directory can still match
them.

Works with any client that reads `SKILL.md`: Claude Code, Codex, Copilot, Cursor, Gemini
CLI, DSH, and the rest of the skills CLI's 75+ targets.

## Install

```bash
npx skills add gaohongkui/skills          # all skills, auto-detected clients
npx skills add gaohongkui/skills --list   # list without installing
```

Install a single skill by pointing at its directory:

```bash
npx skills add https://github.com/gaohongkui/skills/tree/main/skills/handoff-writer
```

Skills land in `.agents/skills/` (project) or `~/.agents/skills/` (global) and are linked
into each client's own directory. No clone, no build step required to consume them.

Prefer not to touch a terminal? Paste this into your agent — it installs the skill and
uses it in one go:

```text
帮我安装 gaohongkui/skills 里的 skill-rsi，然后用它改造我的 <你的 skill 路径>
```

## How this repo is built

```text
skills/<name>/SKILL.md      ← the only place a skill is written
├── scripts/                optional executable helpers
├── references/             optional long docs, loaded on demand
├── assets/                 optional templates and fixtures
└── evals/                  optional trigger + output evaluations
        │
        │  npm run build
        ▼
index/skills.json · index/llms.txt · README tables · .claude-plugin/marketplace.json
```

The generated files carry a banner and are checked in CI (`npm run check`) — a stale
catalog fails the build rather than silently misleading a reader. The README table is
generated into **both** language variants from the same source, so they cannot diverge.

## Before you push: privacy & sensitive-data check

**This repository is public. A push is not a draft.** GitHub, the skills CLI, and
skills.sh snapshot and mirror `SKILL.md`; public repos are scraped within minutes of the
first push. Deleting a commit later does not un-publish it.

Every skill, every push — read
[`docs/publishing-checklist.md`](./docs/publishing-checklist.md) and run:

```bash
npm run privacy              # scans for secrets, PII, internal hosts, machine paths
npm run ci                   # validate + generated-files-in-sync + privacy
git diff --cached            # read every added line — the scanner cannot judge context
```

The gate exists because skill files are shared far beyond this repo: they are pasted into
chat windows, other agents' contexts, issues, and third-party directories.

| Check | Examples of what must not ship |
| --- | --- |
| **Personal data** | real names beyond the copyright line, home addresses, personal email / phone / ID numbers, colleague or customer names, chat screenshots, calendar or ticket dumps |
| **Secrets** | API keys, tokens, passwords, private keys, `.env` files, cookies, signed URLs, connection strings |
| **Internal-only material** | employer-internal hostnames and wiki URLs, project codenames, unreleased roadmaps, non-public metrics, IM exports |
| **Machine fingerprints** | absolute home paths (`/Users/<name>/…`), private IPs, hostnames, device IDs, shell history |
| **Third-party content** | copied code, docs, images, or data you may not redistribute |

If something sensitive already landed: **rotate the credential first**, then clean history
with `git filter-repo` and force-push. If it is already public, treat the secret as
compromised — rewriting history removes the bytes from your remote, not from mirrors,
forks, or caches. Full procedure in the
[checklist](./docs/publishing-checklist.md#if-something-sensitive-already-slipped-through).

## Contributing

Read [`docs/adding-a-skill.md`](./docs/adding-a-skill.md). In short:

```bash
mkdir -p skills/my-skill && $EDITOR skills/my-skill/SKILL.md
npm run build && npm run ci
```

Rules that matter: six frontmatter keys only, `description` must say *when* to use the
skill, `SKILL.md` stays under ~300 lines, and the privacy gate above passes.
